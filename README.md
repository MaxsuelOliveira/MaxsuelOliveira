## Sobre mim

Sou desenvolvedor Full Stack com foco na criação de soluções que resolvem problemas reais de negócio. Atuo principalmente no desenvolvimento de **SaaS**, **automações RPA**, **integrações com inteligência artificial**, APIs e sistemas corporativos.

Meu trabalho combina engenharia de software, segurança e visão de produto: da arquitetura e banco de dados à experiência final do usuário.

- 🤖 Automação de processos, agentes de IA e integrações inteligentes
- ☁️ Plataformas SaaS multiempresa, assinaturas e controle de acesso
- 🔐 Desenvolvimento seguro, autenticação, autorização e proteção de dados
- 🔌 APIs, webhooks e integrações entre sistemas
- 📊 Sistemas de gestão, atendimento, vendas e operações
- 🚀 Arquitetura, implantação, observabilidade e evolução contínua
